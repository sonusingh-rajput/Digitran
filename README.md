# Futurense Clone (React + Tailwind + GSAP + React Router + React Helmet)

An exact, production-ready clone of [Futurense.com](https://futurense.com/) built with modern frontend architecture.

## Tech Stack
- **React 18** (SPA architecture)
- **Tailwind CSS + Webflow Shared Styles** (Full typography, responsive grid, glassmorphic dark theme, custom fonts)
- **GSAP (GreenSock)** (Smooth scroll animations, persona transitions, entrance reveals)
- **React Router Dom (v6)** (Multi-page routing with smooth scroll restoration)
- **React Helmet Async** (Full SEO metadata, Open Graph, Twitter Cards, canonical links)
- **Lucide Icons & Native SVGs** (Exact SVG brand logos and navigation assets)
